📖Petunjuk Permainan

🎮 Cara Bermain Bomber Hero: 1. Pelajari rangkuman materi Sosiologi di setiap awal Level.
2. Masuk ke Arena Game dan amati pertanyaan di bagian atas.
3. Gerakkan Frog Hero ke blok pilihan jawaban menggunakan tombol arah / keyboard (WASD atau Arrow Keys) atau klik/tap langsung pilihan jawaban.
4. Jawaban BENAR: Menerima reward virtual +Rp100.000, +100 poin, dan efek kejayaan.
5. Jawaban SALAH: Bom meledak! Nyawa berkurang dan penjelasan edukatif akan ditampilkan.
⚔️ Duel & Squad Mode: • Dalam Mode Duel, Player 1 (WASD) bertanding langsung melawan Player 2 (Arrow Keys) dalam split-screen.
• Dalam Mode Squad, hingga 4 pemain dapat berpartisipasi menyelesaikan kuis secara bergantian/tim.

🎯Tujuan Pembelajaran (Fase E)

  • Menjelaskan pengertian interaksi sosial sebagai dasar kehidupan bermasyarakat.
  • Mengidentifikasi ciri-ciri interaksi sosial dalam kehidupan sehari-hari.
  • Menjelaskan syarat-syarat terjadinya interaksi sosial (Kontak Sosial & Komunikasi).

📊 Webhook Google Spreadsheet (Guru)

📊Panduan Menyimpan Nilai ke Google Sheets

Ikuti 4 langkah mudah ini agar nilai seluruh siswa otomatis masuk ke Google Spreadsheet Anda:

  1. Buat Spreadsheet Baru di Google Drive Anda.
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode lama, lalu salin (copy) kode di bawah ini ke dalam editor Apps Script.
  4. Klik Terapkan (Deploy) → Penerapan Baru (New Deployment) → Pilih Jenis: Aplikasi Web (Web App) → Akses (Who has access): Siapa Saja (Anyone) → Klik Deploy dan salin URL Web App yang dihasilkan ke input pengaturan game.
Kode Google Apps Script: 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Header otomatis jika sheet masih kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Waktu", "Nama Siswa", "Kelas", "Mode Game", "Level / Status", "Total Poin", "Virtual Reward", "Benar", "Salah", "Akurasi"]);
    }
    
    sheet.appendRow([
      new Date(),
      data.nama || "-",
      data.kelas || "-",
      data.mode || "SOLO",
      data.level || "SELESAI",
      data.score || 0,
      "Rp" + (data.reward || 0).toLocaleString("id-ID"),
      data.correct || 0,
      data.wrong || 0,
      data.accuracy || "0%"
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"result":"success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"result":"error", "error": err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
